# Финансовая Жаба

Telegram-бот для учёта долгов и кредитов: помогает не потерять платежи и вовремя напоминает о них. Живёт в Telegram как @finansovaya_jaba_bot.

## Возможности
- учёт разных типов долгов: потребкредит, ипотека (аннуитет), долг другу, кредитная карта
- оценка «опасности» долга по проценту использования лимита и сроку
- напоминания о платеже: за 3 дня, за 1 день и в день платежа
- еженедельные отчёты по расписанию

## Стек
Python, aiogram 3, SQLite, APScheduler. Деплой: Ubuntu VPS, systemd.

## Запуск
1. Клонировать репозиторий и создать виртуальное окружение:
       python3 -m venv venv && source venv/bin/activate
       pip install -r requirements.txt
2. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN` (токен от @BotFather) и `DB_PATH`.
3. Запустить:
       python bot.py

## Структура
- `bot.py` — точка входа
- `handlers.py` — обработчики команд и сообщений
- `database.py` — работа с SQLite
- `scheduler.py` — напоминания и отчёты
- `config.py` — настройки из `.env`
- `phrases.py`, `milestones.py` — тексты и достижения бота
